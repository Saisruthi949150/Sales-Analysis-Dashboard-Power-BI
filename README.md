# 📊 Sales Analysis Dashboard – Power BI

# 📌 Project Overview

The Sales Analysis Dashboard is an interactive Power BI project designed to analyze sales performance, identify product trends, and understand regional sales contributions. It provides meaningful insights through interactive visualizations, KPIs, yearly comparisons, and dynamic filters.

The dashboard transforms raw sales data into useful business insights, helping users understand sales trends, monitor performance, and make data-driven decisions.

# 🎯 Project Objectives

- Analyze overall sales performance.
- Identify top-performing products and categories.
- Compare sales across different years.
- Understand regional sales contributions.
- Track important business KPIs.
- Identify trends and patterns in sales data.

# 🛠️ Tools & Technologies Used

- Power BI Desktop – Dashboard development and data visualization.
- Power Query – Data cleaning and transformation.
- DAX – Calculated measures and KPIs.
- Microsoft Excel – Dataset storage and data preparation.

# 📈 Key Features

- Sales Overview: Provides a summary of overall sales performance using key metrics.
- Sales Comparison: Compares sales performance across different periods.
- Product Analysis: Identifies product trends and sales contributions.
- Regional Analysis: Analyzes sales performance across different regions.
- Interactive Filters: Allows users to explore data based on different categories and time periods.
- KPI Monitoring: Displays important business metrics for sales performance tracking.
